## 七、快速命令参考表

```bash
# 开发相关
pnpm dev              # 启动开发服务器
pnpm build            # 构建生产版本
pnpm start            # 运行生产版本
pnpm lint             # 代码检查

# Supabase 相关
pnpm supabase start   # 启动本地 Supabase
pnpm supabase status # 检查状态

# shadcn/ui 相关
pnpm dlx shadcn-ui@latest add button  # 添加组件
```

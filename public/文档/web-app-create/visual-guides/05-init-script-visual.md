# 🔧 项目初始化脚本 - 视觉化教程

## 脚本概述

**文件名**: `scripts/init-project.sh`  
**用途**: 一键初始化完整的 Next.js + Supabase 项目  
**使用方式**: `./scripts/init-project.sh <project-name>`

## 详细步骤说明

### 步骤 1: 环境检查

```
┌─────────────────────────────────────────────────────────────────┐
│  步骤 1: 环境检查                                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1.1 检查 Node.js 是否安装                                       │
│      if ! command -v node &> /dev/null; then                   │
│          echo "❌ Node.js 未安装"                               │
│          exit 1                                                 │
│      fi                                                        │
│                                                                 │
│  1.2 检查 Node.js 版本 (需要 18+)                               │
│      NODE_VERSION=$(node -v | cut -d'v' -f2 | cut -d'.' -f1)  │
│      if [ "$NODE_VERSION" -lt 18 ]; then                       │
│          echo "❌ Node.js 版本过低，需要 18+"                  │
│          exit 1                                                 │
│      fi                                                        │
│                                                                 │
│  1.3 检查/安装 pnpm                                             │
│      if ! command -v pnpm &> /dev/null; then                  │
│          npm install -g pnpm                                    │
│      fi                                                        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

│  pnpm create next-app@latest "$PROJECT_NAME" \                 │
│      --typescript \                                            │
│      --tailwind \                                              │
│      --eslint \                                                │
│      --app \                                                  │
│      --src-dir \                                              │
│      --import-alias "@/*" \                                    │
│      --use-pnpm                                               │
│                                                                 │
│  参数说明:                                                      │
│  ┌────────────────┬──────────────────────────────────────┐    │
│  │ 参数           │ 说明                                 │    │
│  ├────────────────┼──────────────────────────────────────┤    │
│  │ --typescript  │ 使用 TypeScript                     │    │
│  │ --tailwind    │ 使用 Tailwind CSS                   │    │
│  │ --eslint      │ 配置 ESLint                         │    │
│  │ --app         │ 使用 App Router                     │    │
│  │ --src-dir     │ 使用 src 目录                      │    │
│  │ --import-alias│ 导入别名 @/*                       │    │

### 步骤 3: 安装依赖

```
┌─────────────────────────────────────────────────────────────────┐
│  步骤 3: 安装依赖                                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  3.1 Supabase 相关依赖                                          │
│      pnpm add @supabase/supabase-js @supabase/ssr             │
│                                                                 │
│      ┌─────────────────────────────────────────────────────┐    │

│      echo "y" | pnpm dlx shadcn-ui@latest init                │
│                                                                 │
│  3.3 安装常用 UI 组件                                           │
│      pnpm dlx shadcn-ui@latest add \                          │
│          button card input label textarea \                   │
│          form select checkbox switch slider \                  │
│          table badge avatar alert toast \                     │
│          dialog dropdown-menu separator skeleton progress     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

├─────────────────────────────────────────────────────────────────┤
│                                                                 │
